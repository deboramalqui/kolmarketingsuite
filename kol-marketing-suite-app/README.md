# Marketing KOL Suite - Versión AI Studio

Aplicación modular e independiente de la plataforma **Marketing KOL Suite**, desarrollada con React, TypeScript y Vite.

## Características incluidas:
- **Gestión integral de campañas**: Ciclo de vida completo (Borrador, En revisión, Aprobada, Activa, Pausada, Finalizada).
- **Editores y vistas previas realistas de anuncios**:
  - Editor interactivo para Google Search Ads (Títulos, Descripciones, URLs, extensiones y preview de escritorio/móvil).
  - Editor interactivo para Meta Ads (Instagram Feed/Stories, Facebook Feed) con previsualización en vivo.
- **Asistente de datos y analítica predictiva**: Métricas clave, estimaciones de ROAS, CPA, conversiones y recomendaciones automáticas.
- **Identidad visual consistente**: Paleta de colores oficial (azul KOL, acentos y tipografía refinada).

## Instrucciones para ejecutar:
```bash
# 1. Ingresar a esta carpeta
cd kol-marketing-suite-app

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
```
