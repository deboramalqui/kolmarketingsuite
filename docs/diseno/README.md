# Prototipos de diseño (referencia, no son parte de la app)

Archivos HTML autónomos: se abren con doble clic. Los textos, cifras y nombres de cuenta son de ejemplo y están a validar.

- `prototipo-botones-cabecera.html`: cabecera con un solo control de estado y actualización (con estados: al día, actualizando, error, datos viejos), engranaje para Conexiones y panel lateral para "Preguntar". Tiene un selector para comparar con los tres botones actuales.
- `prototipo-anuncio-realista.html`: vista previa de anuncios de Instagram y Facebook como se ven de verdad (foto de perfil circular con la hoja, lockup como sello sobre la imagen, texto cortado a 125 caracteres).
- `prototipo-anuncio-google-search.html`: anuncio de Google Búsqueda (solo texto) con límites reales de caracteres, combinaciones, enlaces de sitio, destacados y palabras clave.

Reglas de contenido: derecho inicial US$ 3.000 exactos (nunca "desde"); decir "10 locales" sin "en el país"; no nombrar Buenos Aires como zona con locales; sin signos de exclamación.
